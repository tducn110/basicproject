Starting from an empty board, play X(4,7), O(0,0), X(5,7), O(1,0), X(7,7), O(0,1), X(8,7), O(1,1). All eight placements are distinct and in bounds, neither player has won, and X is next. The gap belongs to the radius-two candidate set because it is within that distance of existing X stones. Directional assessment finds two X stones on each horizontal side, so the hypothetical placement gives 1 + 2 + 2 = 5 and receives the immediate-win flag. O has no immediate winning completion in this position, making the assessed tactical set T = {(6,7)}. With a nominal cap of one, the soft-cap rule retains max(1, |T|) = 1 candidate: the winning gap [10].
For a fixed-root Minimax or Alpha-Beta search with root X and positive depth, applying that candidate creates a terminal child at root distance one. Terminal detection precedes the horizon evaluator, so its value is U = M − 1 = 99,999,999 with M = 100,000,000. Both algorithms therefore return the same winning decision on this selected tree. This example demonstrates tactical membership and terminal backup. Because only one root candidate is retained, the trace contains no Alpha-Beta cutoff [10].
The hypothetical placement raises move_count from eight to nine. After evaluating the child, undo clears (6,7) and restores the count to eight, leaving the original decision position available to the caller. These cell-and-count changes take constant time, while candidate generation and assessment retain the costs analyzed earlier.
